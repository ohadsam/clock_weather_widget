# Changelog

## 0.1.0
- Foundation: native Android app with a transparent, resizable home-screen widget (flip cards, digital, analog, minimal).
- Hebrew + Gregorian date, holidays, weather (Open-Meteo) with max/min and rain/sunny outlook, next alarm, today's calendar events banner, extra time zones, sunrise/sunset.
- App: live widget preview, settings (look, what to show, places, time zones, alarm app, calendar, units), weather details by hour.
